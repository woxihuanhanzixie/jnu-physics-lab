# JNU大学物理实验

可用于Claude, Codex, 豆包, Workbuddy, QCoder等常见智能体的使用技能，支持**课前预习**和**实验后报告**两个模式。根据本次教材和真实资料，直接输出可手抄的中文正文。

## 安装与调用

提供本次教材后：

> $jnu-physics-lab 课前预习：根据这些教材图片，生成可手抄的预习报告。

提供本次教材、原始记录、仪器规格及教师要求后：

> $jnu-physics-lab 实验后报告：先确认大纲，再核对数据，完成计算、不确定度、结论、误差分析和思考题。

> $jnu-physics-lab 实验后报告：保留前面预习内容，只补齐实验后的部分。

这些模式名称是文字选择词，不是两个独立按钮。明确的自然语言请求也可选择模式；阶段不明时询问。同一对话可续用已确认材料，新对话需重新提供相关资料。

## 输出与边界

- 预习：目的、原理公式、必要图示、仪器与步骤、空白记录表、注意事项。
- 实验后：先确认大纲，核对读数和精度，再按“公式→代入→结果”书写，计算A/B类及合成不确定度；更正数据后更新全部受影响结果。
- 正文直接交付，不使用可编辑写作框，不默认生成文件。不照抄教材，不编造数据或结论。
- 缺本次教材不生成实验专属完整报告；往届报告只参考格式。可核对已提供的算术，但不能冒充方法已核验。
- 仪器分辨力不等于误差限；相关误差不因取平均自动减小；条件估算必须标明假设和未覆盖来源。
- 必要示意图用可用生图模型生成并检查；数据图用真实数据精确绘制。正文标明放图位置并显示实际图。工具不可用时说明限制。

## 文件

- `SKILL.md`：模式选择与共同规则。
- `references/prelab.md`：预习流程、图示检查及正文模板。
- `references/postlab.md`：实验后确认、计算、复核、书写与更正流程。
- `references/acceptance-cases.md`：行为验收场景。
- `agents/openai.yaml`：技能显示信息。
- `AGENTS.md`：维护约定。

结构验证不等于全部端到端模型测试。公开文件不包含教材扫描件、学生原始报告、个人信息或错误图像。
