# JNU大学物理实验

用于大学物理实验**课前预习**的个人 Codex 技能。依据用户提供的本次教材或讲义，输出可直接手抄的中文预习报告。

## 使用

将本仓库内容放入个人技能目录中的 `jnu-physics-lab/`，保持 `SKILL.md` 位于该目录根部。已有本地安装无需重复复制。

提供本次教材照片或讲义，然后输入：

> 请使用 $jnu-physics-lab，根据我提供的教材完成本次实验预习，直接输出正文，并生成必要图示。

## 输出与边界

- 实验目的、原理和主要公式（含符号解释）、仪器与主要步骤、空白原始数据表、关键注意事项。
- 直接聊天正文输出，不使用可编辑写作框，不默认另建报告文件。
- 必要图示使用可用生图模型生成并检查，在正文标明画图位置；生图依赖运行环境的工具支持。
- **没有本次教材或讲义时，不生成实验专属报告；往届报告只能作为格式参考。**
- 不编造数据、仪器参数或实验结论，不将预习扩大为实验后报告。

## 文件

- `SKILL.md`：技能入口、完整规则与正文模板。
- `agents/openai.yaml`：显示名称和默认调用提示。
- `references/acceptance-cases.md`：维护时的行为验收场景。
- `AGENTS.md`：仓库维护约定。

已通过技能结构验证；验收场景是维护标准，不代表已经完成全部端到端模型测试。仓库不包含教材扫描件、学生报告照片和个人信息。本项目为个人学习辅助工具，并非学校官方发布。
