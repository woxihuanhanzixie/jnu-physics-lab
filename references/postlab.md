# 实验后完整报告模式

本模式依据本次教材与真实记录，补齐实验后报告。先确认大纲，再执行正式计算和书写；默认续写已有预习部分。不得把课前空白表、参考报告或生图模型生成数字当作实测数据。

## 1. 接收材料，先确认大纲

- 查看本次教材、原始数据、已有报告、教师格式及思考题。辨认重复、旋转、缺页、涂改和不清楚的读数；可为辨认调整查看方向，保留原始文件。
- 先提出核心大纲，等待用户确认。默认为：数据处理（含计算与不确定度）→ 实验结果与结论 → 误差分析 → 思考题。说明是否需要图，按已有报告承接编号。
- 教师要求与实验性质决定是否增加拟合、校准、作图、对照等内容，不把任何实验强制套成三次测量或最小偏向角法。
- 在大纲阶段集中列出关键缺口；可以同步做只读转录和算术检查，但不抢先交付完整计算稿。用户已确认同一大纲后不要重复索要批准。

## 2. 建立可核对的数据表

- 分开记录：原始读数、用户已有计算、教师给定值、仪器规格、待确认项。每项保留单位和来源；缺失值留空，绝不按0处理。
- 将可读原始记录转录为表，逐项检查单位、有效位数、进位借位、零刻度跨越、正负方向和数量级。原始记录未改变，算错的计算栏可以更正。
- 模糊数字逐项列出具体候选，索要明确值；“是的”只有在唯一具体候选清楚时才算确认。不能将只确认列名当成确认整行数字，不能由已有差值反推原始值。
- 区分游标格数、主尺分格、最小分度值、准确度及允许误差。“相邻差一”若没有单位须确认；只有格数不能确定分辨力。
- 明确共用零点、共用标定值及重复测量是否独立。若某个基准只读一次而多次复用，后续平均的传播必须保留相关性。
- 异常值、双游标不一致或重复性较差应指出具体证据和可能解释；不得为接近预期而改数或删点。只有明确依据和用户确认后才更正原始记录或排除数据，并说明原因。
- 集中询问尚未确认的关键项，先推进不依赖这些项的检查；不反复追问已确认信息。关键缺口未补齐时仅交付已确定部分，不能宣称完整结果。

## 3. 计算与复核

- 按“公式 → 数值代入 → 结果 → 必要解释”组织。少量重复测量逐组列式；数据很多时给代表性完整代入和全部结果表，确保可追溯。
- 先计算派生量，再按测量模型求平均、拟合或最终物理量；区分“先平均再非线性换算”和“逐次换算再平均”，依教材要求选择并写明。
- 用计算工具完成数值工作；再以不同形式复核关键结果，例如角度先转整数角秒再与借位运算对照、代回原式、解析导数与数值差分对照。重复运行同一公式不是独立验证。
- 中间计算保留足够位数，最终按不确定度统一修约。避免把角分当成小数度；含三角函数的灵敏系数按弧度导出时，角度不确定度也必须换算为弧度。
- 无可用计算工具时如实说明计算及核查范围，不声称完成工具验证。

## 4. 不确定度评定

默认分别评定A类、B类，并给出合成标准不确定度和相对标准不确定度。用户或教师另有要求时遵从，但指出明显不适用的处理。

- A类：独立等精度重复测量的均值采用 u_A(x̄)=sqrt[Σ(x_i−x̄)²/(N(N−1))]。解释N和偏差；N不足、数据相关或测量模型不符时不能套用。重复值相同导致A类为0不代表没有测量不确定度。
- B类：列出实际来源，如校准证书、仪器允许误差、分辨力及给定常量误差。写明误差界限、概率分布、除数及依据。证书给扩展不确定度时依据其覆盖因子换算。
- 仅已知分辨力q时，不能称它为仪器允许误差。若采用舍入模型±q/2、均匀分布，则单次读数标准不确定度为q/sqrt(12)，明确这是条件估算，不含全部仪器误差。核查与重复性分量是否重复计入；无法分离时说明限制。
- 用实际测量表达式传播每个读数，不能凭“两次读数”“两个游标”机械乘除sqrt(2)。均值是否除sqrt(N)由误差的独立性决定，不由A/B分类决定。共用零点、校准偏差等相关分量不会因重复而自动缩小。
- 一般传播式：u_c²(y)=Σc_i²u²(x_i)+2Σ_(i<j)c_i c_j cov(x_i,x_j)，c_i=∂f/∂x_i。列出本实验所用偏导、单位、代入过程；只有说明不相关时才删去协方差项。
- 顶角、质量、长度、标定系数等参与公式的输入都要检查。不知道其误差不等于它精确；可在明确条件下暂不计，但最终结果必须标为条件估计，说明未覆盖的来源。会影响最终结论的缺口需先确认。
- 不默认把t因子乘到A类标准不确定度上。若课程要求置信区间或扩展不确定度，分别说明置信水平、自由度、覆盖因子和所用方法；不得把k=2无条件称为严格95%覆盖。
- 最终以 y±u_c(y) 或 y±U 给出，标明标准/扩展不确定度及适用条件，保持测量值与不确定度末位一致。相对不确定度与相对误差不可混称。

## 5. 正文交付

确认数据与计算条件后，按已接受大纲一次输出可手抄正文；不只提供文件或片段拼接说明。

### 数据处理
列出必要实验参数及来源、修正后的派生量表、各项计算公式和代入、平均值或拟合、不确定度各分量及传播结果。已在前文明确的条件可简短引用；影响结论的假设必须在报告中可见。

### 实验结果与结论
写清方法、被测量、条件和规范结果。没有可靠同条件参考值，不编写相对误差或“与理论一致”；有参考值时注明出处与可比条件。不能把仅测一种波长写成验证色散，也不虚构观察现象。

### 误差分析
围绕本次数据与实际操作解释主要来源、影响及可行改进；区分记录中已证实的情况与可能原因。不重复不确定度推导，不把所有异常都称为操作失误。

### 思考题
依据本次教材逐题作答，问题与回答直接呈现，解释物理原因；不沿用其他实验的题目。

### 图像
- 已有正确且足够的原理图无需重画。需要补充光路、电路或装置图时读取 [prelab.md](prelab.md) 的“图像必须实际交付”，用可用生图模型生成并检查。
- 数据曲线、回归图和误差棒用真实数据及精确绘图工具生成，不能使用生图模型编造点位或拟合线。核对坐标、单位、误差棒含义和拟合参数。
- 对每张所需图，在对应正文写 **【本处需要画上图像：图名；必要标注】**，紧接最终图及图注。无新增图时可简短说明，不填无意义占位。

## 6. 用户更正后的处理

接受明确修正后保留其来源，重新计算所有依赖该值的角差、均值、拟合、不确定度、表格、图像和结论。只问不清楚的部分；不能只改表格却沿用旧结果。按用户需要输出修订段或完整稿；若先只核对算术，说明最终报告哪些部分尚待更新。

交付前核对：材料与数据已确认、大纲已接受、所有公式可核对、图与表一致、单位和修约一致、不确定度依据可追溯、没有伪造验证或宣称完整覆盖未知误差。
